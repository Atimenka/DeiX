Посмотри текущую ветку `arena/01a0b7dc-deix` и исправь **все compiler warnings**, показанные в приложенном логе.

Сейчас сборка заканчивается примерно на:

`deix_kernel (lib) generated 109 warnings`

Цель: после cleanup выполнить

`cargo +nightly build --release`

и получить **0 warnings**, без маскировки проблем через глобальный `#[allow(dead_code)]`.

### Главное правило

Не просто добавляй `#[allow(dead_code)]`.

Для каждого warning реши одно из трёх:

1. код больше не нужен → удалить;
2. код нужен → реально использовать/подключить;
3. код является сознательным public API/future scaffold → только локальный `#[allow(dead_code)]` с коротким объяснением, и только если удаление действительно ломает архитектуру.

Приоритет — удаление мёртвого кода.
