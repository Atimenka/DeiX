Мои устройства

В DeiX выполните dev link: система покажет код вида XXXX-XXXX, действует 10 минут. Заявку на токен можно подать только для привязанного устройства.

Ключ разблокировки dev-режима

Одноразовый ключ для конкретного устройства. В DeiX выполните dev id, вставьте Device ID сюда, получите ключ и введите его в DeiX командой dev unlock КЛЮЧ, затем dev on. Сеть в момент ввода не нужна. Ключ показывается один раз и на сайте не хранится.


            

            
История выданных ключей и имена устройств хранятся только в этом браузере и зашифрованы вашим паролем (AES-256-GCM). На сервере их нет.

Синхронизация настроек

            
Настройки рабочего стола синхронизируются между устройствами. В DeiX выполните cloud sync для отправки текущих настроек и cloud pull для загрузки сохранённых.

            

          


          

            
Общий буфер обмена

            
Текст между устройствами. В DeiX: cloud clip set "текст" для отправки, cloud clip get для получения.
