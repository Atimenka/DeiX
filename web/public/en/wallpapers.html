Ten AI-generated pictures. Download a PNG for your own desktop, or set one in DeiX OS with a single command.

How to set one in DeiX OS

Press “Command for DeiX OS” and paste it into the system terminal. The OS downloads the picture over HTTPS, saves it to /userdata/wallpaper.bmp and switches the wallpaper style to Custom. The files are sized for the OS file limit (268 KiB), so the OS does not shrink them. A working network is required: in QEMU that is the -netdev user and -device rtl8139 flags.

The pictures are AI-generated and free to use in DeiX OS.
