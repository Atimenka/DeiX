How to run

Unpack the file if it is archived (.gz, .xz or .zip) and run the image as a virtual machine disk:

qemu-system-x86_64 -m 512M \
  -drive format=raw,file=deix.img \
  -netdev user,id=n0 -device rtl8139,netdev=n0

Compare the SHA-256 of the downloaded file with the checksum on the release card: on Linux use sha256sum file, on Windows certutil -hashfile file SHA256.
