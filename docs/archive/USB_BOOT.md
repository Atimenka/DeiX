# Запуск DeiX с флешки на реальном железе

Цель — проверить открытый драйвер NVIDIA на настоящей карте
(в вашем случае GT 520M / GF119). В QEMU это невозможно: эмуляции
карт NVIDIA не существует, команда `nvidia` там честно сообщает
«карта не найдена».

## 1. Собрать образ

```bash
cd DeiX
bash build.sh
ls -lh build/deix_disk.img     # ~10 МБ
```

## 2. Записать на флешку

**Данные на флешке будут стёрты полностью.** Образ пишется как есть,
с MBR и таблицей разделов — форматировать заранее не нужно.

### Linux

```bash
lsblk                                    # найдите свою флешку!
sudo umount /dev/sdX*                    # отмонтировать, если смонтирована
sudo dd if=build/deix_disk.img of=/dev/sdX bs=4M conv=fsync status=progress
sync
```

`/dev/sdX` — **диск целиком** (`/dev/sdb`), а не раздел (`/dev/sdb1`).
Перепроверьте букву: ошибка здесь уничтожит данные не на той машине.

### Windows

Подойдёт любая из программ:

* **Rufus** — выбрать образ, режим записи **DD Image** (не ISO!);
* **balenaEtcher** — умеет писать `.img` напрямую;
* **Win32 Disk Imager** — классический вариант для `.img`.

Ключевой момент: писать нужно **посекторно** (DD/raw), а не «создать
загрузочный носитель из ISO». Это не ISO, это образ диска.

## 3. Загрузиться

1. Вставьте флешку, включите компьютер, зайдите в загрузочное меню
   (обычно **F12**, **F11**, **Esc** или **F8** — зависит от вендора).
2. Выберите флешку в списке.
3. **Обязательно отключите Secure Boot** и включите **Legacy / CSM**
   режим: DeiX грузится через классический BIOS-MBR, UEFI он не
   поддерживает.

## 4. Что проверять

После входа в систему (создайте аккаунт при первом запуске):

```
nvidia            # найдёт карту, покажет чип и поколение
nvidia dump       # сохранит дамп регистров в файл NVIDIA.TXT
cat NVIDIA.TXT    # прочитать дамп
hal               # самопроверка прослойки (нужна сетевая карта)
gpu info          # какой видеоадаптер увидело ядро
```

### Что ожидается на GT 520M

```
[nvidia] карта найдена: 10DE:0DEC
[nvidia] BAR0 = 0x........ (16 МиБ регистров)
[nvidia] NV_PMC_BOOT_0 = 0x0d9........
[nvidia] чип 0x0d9 -> Fermi (GF1xx)
Прошивка для установки видеорежима: НЕ ТРЕБУЕТСЯ
Процессор GSP: отсутствует (появился в Turing)
```

Если `NV_PMC_BOOT_0` прочитался и начинается с `0x0d9` — прослойка
достучалась до реальной карты через MMIO. Это и есть та обратная
связь, которой не хватало: дальше можно браться за modesetting,
имея возможность проверять каждый шаг.

## Если не загружается

| Симптом | Причина |
|---|---|
| BIOS не видит флешку | не отключён Secure Boot / не включён Legacy-CSM |
| `loading stage2...` и стоп | BIOS не поддерживает LBA-чтение (int13 AH=42) |
| Чёрный экран после лого | видеорежим не поднялся, попробуйте `-vga std`-совместимый режим |
| Перезагрузка по кругу | несовместимость BIOS, попробуйте другой USB-порт (лучше USB 2.0) |

Лог загрузки дублируется в COM1. Если у машины есть последовательный
порт, его можно снять переходником USB-RS232 на 115200 8N1 — там
виден весь вывод ядра, даже когда экран молчит.

## Важно про данные

DeiX шифрует свой том паролем первого аккаунта (XTS-AES-256, слоты
LUKS). Флешка после записи содержит только DeiX — обычные файлы на
неё положить нельзя, пока она используется как загрузочная.
